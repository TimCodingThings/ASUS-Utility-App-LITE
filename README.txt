ASUS Utility LITE 1.1.0

Run ASUS Utility LITE.exe from a permanent folder and accept the administrator
prompt. Exit G-Helper or the previous Lite app before launching this version.
Closing the window keeps the app in the system tray; use Exit to stop it.

The renamed app imports previous Lite settings and its startup entry on first
launch. Current settings: %LOCALAPPDATA%\ASUS Utility LITE\settings.xml

See README.md for controls, requirements, testing limits, downloads, and source.
Run Build.ps1 to build locally and Test.ps1 for the 24 offline checks.
Run ASUS Utility LITE Diagnostics.cmd for a local, read-only diagnostic report.
